## 詳解

## 一、雲端概念

**1.** 答案：**A**

不改程式碼與架構、原樣搬上雲，是 Rehost（lift and shift）。
易混淆：Replatform 會做小幅度的調整（例如換成代管資料庫）；Refactor 會重新設計架構。

👉 不改程式碼、原樣搬 -> Rehost。

**2.** 答案：**C**

改用 SaaS 產品取代自己維護的系統，是 Repurchase。
易混淆：Retire 是直接關閉不用；Retain 是暫時留在地端。

👉 換成 SaaS 產品 -> Repurchase。

**3.** 答案：**B**

核心架構不變，只把資料庫換成 RDS 這類代管服務，是 Replatform。
易混淆：Rehost 連資料庫都不換；Refactor 會重新設計成微服務或無伺服器等雲原生架構。

👉 小幅調整、換成代管服務 -> Replatform。

**4.** 答案：**D**

已沒有人使用、直接關閉，是 Retire。
易混淆：Retain 是仍然需要，只是暫時不遷移、留在原地。

👉 沒人用、關掉 -> Retire；還要用但先不搬 -> Retain。

**5.** 答案：**C**

從數週縮短到數分鐘、加速創新，是敏捷性。
易混淆：彈性談的是容量跟著需求伸縮。

👉 速度變快、加速創新 -> 敏捷性。

**6.** 答案：**A**

容量隨需求自動擴增與縮減，只為實際使用付費，是彈性。
易混淆：經濟規模是 AWS 聚合大量客戶的用量，使每單位成本降低；敏捷性談的是速度。

👉 容量跟著需求伸縮 -> 彈性。

**7.** 答案：**C**

CAF 的 Governance 視角涵蓋治理與雲端財務管理，包含成本可視性與風險管理。
易混淆：Business 視角談的是業務價值與策略對齊，不是成本管控機制。

👉 成本管控、財務、風險 -> Governance；業務價值、策略 -> Business。

**8.** 答案：**D**

提升員工技能、組織文化、訓練，是 CAF 的 People 視角。
易混淆：Operations 談的是營運流程，如監控、事件管理；Platform 談的是技術架構。

👉 人員技能、組織文化、訓練 -> People。

## 二、安全與合規

**9.** 答案：**B**

SCP 在組織層級設定成員帳戶的權限上限，即使帳戶管理員也無法超越。
易混淆：IAM Policy 是設定在身分上；NACL 與 Security Group 是網路層的控制。

👉 組織層級、權限上限 -> SCP。

**10.** 答案：**AC**

SCP 設定的是權限上限，帳戶管理員也無法超越。
易混淆：SCP 本身不會授予權限，仍需要 IAM 政策搭配；SCP 不影響 Organizations 的管理帳戶，而且不能取代 IAM 政策。

👉 SCP 只限制上限、不授予權限；實際權限仍由 IAM 決定。

**11.** 答案：**D**

Network ACL 在子網路層級運作，是無狀態的，並且可以明確拒絕特定 IP。
易混淆：Security Group 在執行個體層級、有狀態，只能設定允許規則，不能明確拒絕。

👉 子網路層級、無狀態、可拒絕 -> NACL；執行個體層級、有狀態、只允許 -> Security Group。

**12.** 答案：**C**

IAM Identity Center 提供員工單一登入，存取多個 AWS 帳戶與應用程式。
易混淆：Cognito 是為應用程式的終端使用者設計，不是為員工存取 AWS 帳戶。

👉 員工、多帳戶單一登入 -> IAM Identity Center。

**13.** 答案：**A**

Cognito 讓應用程式的終端使用者註冊、登入，並可整合社群帳號。
易混淆：IAM Identity Center 是給公司員工使用，不是給一般消費者。

👉 App 的終端使用者、註冊登入、社群帳號 -> Cognito。

**14.** 答案：**B**

Macie 使用機器學習在 S3 中找出個人識別資訊等敏感資料。
易混淆：GuardDuty 偵測威脅行為；Inspector 掃描軟體漏洞；Config 記錄資源組態變更。

👉 S3 的敏感資料、PII -> Macie。

## 三、雲端技術與服務

**15.** 答案：**AB**

Instance store 是連接主機的實體儲存，延遲低、IOPS 高，但執行個體停止或終止後資料消失。
易混淆：可建立快照、獨立於生命週期永久保存，都是 EBS 的特性；Instance store 不能跨 AZ 掛載。

👉 實體連接、低延遲、停止後消失 -> Instance store；永久保存、可快照 -> EBS。

**16.** 答案：**D**

EBS 是可持久保存的區塊儲存，可以建立快照，適合用作資料庫磁碟。
易混淆：Instance store 在停止或終止後資料消失；EFS 是檔案儲存，不是單一執行個體用的區塊儲存。

👉 持久保存、區塊儲存、可快照 -> EBS。

**17.** 答案：**B**

EFS 是共用的檔案系統，可以同時掛載到多台 Linux 執行個體，容量自動伸縮。
易混淆：EBS 是區塊儲存，一般只掛到單一執行個體；S3 Glacier 是封存儲存。

👉 多台 EC2 共用檔案系統 -> EFS。

**18.** 答案：**C**

Direct Connect 提供專用的私有連線，不走公共網際網路，頻寬與延遲穩定。
易混淆：Site-to-Site VPN 雖然加密，但走公共網際網路，延遲較不穩定。

👉 專用、私有、不走公網、穩定 -> Direct Connect。

**19.** 答案：**A**

Site-to-Site VPN 可以在短時間內建立加密連線，經過公共網際網路，不需要等待專線。
易混淆：Direct Connect 需要佈建實體專線，通常要等待較長的時間。

👉 快速、加密、走公網 -> VPN。

**20.** 答案：**D**

NAT Gateway 讓私有子網路的資源可以連出到網際網路，但外部無法主動連入。NAT Gateway 會依運作時數與處理的資料量收費，要留意費用。
易混淆：Internet Gateway 讓公有子網路雙向連線；Security Group 是防火牆，不是連線出口。

👉 私有子網路連出網際網路、不被連入 -> NAT Gateway。

**21.** 答案：**C**

Intelligent-Tiering 依存取模式自動在儲存層之間移動資料，適合存取模式不固定的資料。
易混淆：One Zone-IA 只存在單一 AZ，不是為了自動分層；Deep Archive 是長期封存，取回需要等待。

👉 存取模式不固定、自動分層 -> Intelligent-Tiering。

**22.** 答案：**B**

Read Replica 以非同步複寫產生唯讀副本，用來分攤讀取流量。
易混淆：Multi-AZ 是為了高可用與容錯移轉，備用資料庫平時不處理讀取流量。

👉 非同步、分攤讀取 -> Read Replica。

**23.** 答案：**C**

Multi-AZ 以同步複寫維持備用資料庫，主資料庫故障時自動容錯移轉。
易混淆：Read Replica 是非同步，用於分攤讀取，不是為了自動容錯移轉。

👉 同步、容錯移轉 -> Multi-AZ。

**24.** 答案：**B**

Fargate 是容器的無伺服器運算引擎，不需要自己佈建與管理 EC2。
易混淆：EC2 要自己管理執行個體；Lambda 是以函式為單位，不是執行一般容器應用程式；Lightsail 是簡化的虛擬伺服器方案。

👉 執行容器、不管伺服器 -> Fargate。

## 四、帳單、計價與支援

**25.** 答案：**AB**

Budgets 可以設定自訂預算，並在實際或預測超出預算時通知。
易混淆：檢視歷史成本趨勢是 Cost Explorer；估算預期費用是 Pricing Calculator；檢查閒置資源是 Trusted Advisor。

👉 預算、超出時通知 -> Budgets；歷史趨勢 -> Cost Explorer。

**26.** 答案：**D**

Cost Explorer 用圖表檢視與分析過去的成本與用量，並可依服務、帳戶篩選。
易混淆：Budgets 重點是設定預算與通知；Pricing Calculator 是估算未來費用。

👉 分析過去的成本與用量 -> Cost Explorer。

**27.** 答案：**C**

Enterprise Support 提供指派的 Technical Account Manager，是最完整的支援方案。
易混淆：Business Support 提供 24 小時全天候的技術支援，但沒有指派的 TAM。方案細節以官方文件為準。

👉 專屬 TAM -> Enterprise Support。

**28.** 答案：**A**

AWS Organizations 提供合併帳單，把多個帳戶的用量合併計算，可以更快達到數量折扣的門檻。
易混淆：Budgets 只設定預算；IAM Identity Center 是單一登入；Control Tower 是建立與治理多帳戶環境。

👉 多帳戶合併帳單、合併用量 -> Organizations。

**29.** 答案：**AC**

一般而言，資料傳入 AWS，以及同一個可用區域內透過私有 IP 的傳輸，不收費。實際以官方定價為準。
易混淆：傳出到網際網路、跨 Region 傳輸，以及經過 NAT Gateway 處理的資料，都會產生費用。

👉 傳入免費、同 AZ 私有 IP 免費；傳出、跨 Region、NAT 處理要收費。

**30.** 答案：**B**

啟用 Cost allocation tags 並為資源加上標籤，成本報告就可以依專案或部門分類。
易混淆：Budgets 是設定預算與通知；Pricing Calculator 是估算費用；Trusted Advisor 是檢查建議。

👉 依專案、部門分攤成本 -> Cost allocation tags。
