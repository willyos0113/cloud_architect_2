## 一、計價方案（10 題）

**1.** 公司的資料庫伺服器會 24 小時不間斷執行三年，執行個體家族與 Region 確定不會更動，希望取得最大的折扣。哪一個方案最合適？

- (A) On-Demand Instances
- (B) Spot Instances
- (C) Standard Reserved Instances
- (D) Dedicated Hosts

**2.** 公司目前同時使用 EC2 與 Fargate，未來幾個月會更換執行個體家族，也可能把部分工作負載移到其他 Region，希望用一年期承諾換取折扣。哪一個方案最合適？

- (A) Standard Reserved Instances
- (B) Compute Savings Plans
- (C) EC2 Instance Savings Plans
- (D) Spot Instances

**3.** 研究團隊要跑一批基因分析任務，任務可以中斷後重新執行，並且希望成本最低。哪一個方案最合適？

- (A) Spot Instances
- (B) On-Demand Instances
- (C) Compute Savings Plans
- (D) Standard Reserved Instances

**4.** 新創團隊要在兩週內進行一次無法預測用量的活動，期間不能被中斷，也不想簽任何承諾。哪一個方案最合適？

- (A) Standard Reserved Instances
- (B) Compute Savings Plans
- (C) Spot Instances
- (D) On-Demand Instances

**5.** 關於 Savings Plans，下列哪一項敘述正確？

- (A) 承諾使用特定的執行個體類型與數量
- (B) 承諾每小時固定的花費金額（美元／小時）
- (C) 承諾只在特定的可用區域使用
- (D) 承諾每月的資料傳輸量

**6.** 公司已決定使用 Reserved Instances，但擔心一年內架構調整，需要能在期間內更換執行個體家族與作業系統，仍想要折扣。哪一個選項最合適？

- (A) Standard Reserved Instances
- (B) Spot Instances
- (C) Convertible Reserved Instances
- (D) On-Demand Instances

**7.** 下列哪兩項是 Spot Instances 的特性？（選兩項）

- (A) 相較 On-Demand 可節省最多約 90% 的費用
- (B) 當 AWS 需要回收容量時，執行個體可能被中斷
- (C) 保證執行期間不會被中斷
- (D) 必須簽訂一年或三年的承諾
- (E) 最適合需要穩定連續執行的關聯式資料庫

**8.** 公司要把既有以實體 socket 與核心數計價的軟體授權帶上 AWS，需要能看到實體 socket 與核心數以符合授權條款。哪一個選項最合適？

- (A) Dedicated Hosts
- (B) Dedicated Instances
- (C) Spot Instances
- (D) Compute Savings Plans

**9.** 公司只使用 EC2，工作負載固定在單一 Region 的單一執行個體家族，願意接受較低的彈性，換取比 Compute Savings Plans 更高的折扣。哪一個方案最合適？

- (A) Compute Savings Plans
- (B) EC2 Instance Savings Plans
- (C) Spot Instances
- (D) On-Demand Instances

**10.** 在 Reserved Instances 與 Savings Plans 的付款組合中，一般而言哪一種折扣最大？

- (A) 一年期、無預付
- (B) 一年期、部分預付
- (C) 三年期、無預付
- (D) 三年期、全額預付

## 二、Route 53、Global Accelerator、CloudFront 與 ELB 的分工（8 題）

**11.** 全球使用者造訪公司網站，需要降低靜態圖片與影片的載入延遲，並將內容快取在離使用者最近的位置。哪一個服務最合適？

- (A) Amazon Route 53
- (B) AWS Global Accelerator
- (C) Amazon CloudFront
- (D) Application Load Balancer

**12.** 應用程式部署在兩個 Region，需要一組固定的 Anycast IP，讓流量走 AWS 全球骨幹網路，並在 Region 故障時快速切換，不依賴 DNS 快取。哪一個服務最合適？

- (A) AWS Global Accelerator
- (B) Amazon Route 53
- (C) Amazon CloudFront
- (D) Network Load Balancer

**13.** 主要網站發生故障時，需要在 DNS 層依健康檢查結果，自動把使用者導向備援網站。哪一個服務最合適？

- (A) Amazon CloudFront
- (B) AWS Global Accelerator
- (C) Application Load Balancer
- (D) Amazon Route 53

**14.** 應用程式需要依 URL 路徑，把 `/api` 的請求導向一組目標，把 `/images` 的請求導向另一組目標。哪一個服務最合適？

- (A) Network Load Balancer
- (B) Application Load Balancer
- (C) Amazon Route 53
- (D) AWS Global Accelerator

**15.** 應用程式處理極高流量的 TCP 連線，需要極高效能，並且每個可用區域要有一個靜態 IP。哪一個服務最合適？

- (A) Application Load Balancer
- (B) Amazon CloudFront
- (C) Network Load Balancer
- (D) Amazon Route 53

**16.** 下列哪兩項服務的運作範圍限定在單一 Region 內？（選兩項）

- (A) Application Load Balancer
- (B) Amazon Route 53
- (C) Network Load Balancer
- (D) AWS Global Accelerator
- (E) Amazon CloudFront

**17.** 公司在多個 Region 都有部署應用程式，希望 DNS 能依延遲，把使用者導向回應最快的 Region。哪一個服務最合適？

- (A) AWS Auto Scaling
- (B) Amazon CloudFront
- (C) Amazon Route 53
- (D) Application Load Balancer

**18.** 公司的即時遊戲伺服器使用 UDP 協定，玩家遍及全球，需要固定 IP 並改善跨國網路效能。哪一個服務最合適？

- (A) Amazon CloudFront
- (B) Application Load Balancer
- (C) Amazon Route 53
- (D) AWS Global Accelerator

## 三、相似服務的分界（12 題）

**19.** 應用程式需要安全地存放資料庫密碼，並且每 30 天自動輪替。哪一個服務最合適？

- (A) AWS Secrets Manager
- (B) AWS Key Management Service（KMS）
- (C) AWS Artifact
- (D) AWS Certificate Manager

**20.** 公司需要建立並管理用來加密 S3 物件與 EBS 磁碟區的加密金鑰。哪一個服務最合適？

- (A) AWS Secrets Manager
- (B) AWS IAM
- (C) AWS Key Management Service（KMS）
- (D) AWS Artifact

**21.** 稽核人員要求公司提供 AWS 本身的 SOC 與 ISO 合規報告。公司可以從哪裡下載？

- (A) AWS Audit Manager
- (B) AWS Artifact
- (C) AWS Config
- (D) AWS Trusted Advisor

**22.** 公司希望自動蒐集自己帳戶中使用 AWS 的稽核證據，並對照合規框架產生稽核報告。哪一個服務最合適？

- (A) AWS Artifact
- (B) AWS Config
- (C) AWS CloudTrail
- (D) AWS Audit Manager

**23.** 資安團隊要偵測帳戶是否遭入侵，例如異常的 API 呼叫、EC2 與已知惡意 IP 通訊，資料來源包含 CloudTrail、VPC Flow Logs 與 DNS 紀錄。哪一個服務最合適？

- (A) Amazon Inspector
- (B) Amazon GuardDuty
- (C) Amazon Macie
- (D) AWS Config

**24.** 資安團隊要掃描 EC2 執行個體與容器映像中已知的軟體漏洞（CVE）。哪一個服務最合適？

- (A) Amazon Inspector
- (B) Amazon GuardDuty
- (C) Amazon Macie
- (D) AWS Shield

**25.** 下列哪兩項是 Amazon Inspector 的功能？（選兩項）

- (A) 掃描 EC2、容器映像與 Lambda 函數中的軟體漏洞
- (B) 分析 VPC Flow Logs 以偵測異常網路行為
- (C) 持續自動掃描，並以風險分數排序發現項目
- (D) 找出 S3 儲存貯體中的個人識別資訊（PII）
- (E) 記錄資源組態的變更歷程

**26.** 公司要在檔案上傳到 S3 時自動執行一段程式，不想管理任何伺服器，並且只依實際執行時間付費。哪一個服務最合適？

- (A) Amazon EC2
- (B) AWS Elastic Beanstalk
- (C) Amazon Lightsail
- (D) AWS Lambda

**27.** 開發者只想上傳 Java 應用程式的程式碼，由 AWS 自動佈建 EC2、負載平衡與 Auto Scaling 並代為管理。哪一個服務最合適？

- (A) AWS CloudFormation
- (B) AWS CodeDeploy
- (C) AWS Elastic Beanstalk
- (D) AWS Lambda

**28.** 團隊要用 JSON 或 YAML 範本定義整套基礎設施，並能重複建立相同的環境。哪一個服務最合適？

- (A) AWS CloudFormation
- (B) AWS Elastic Beanstalk
- (C) AWS CodeDeploy
- (D) AWS Systems Manager

**29.** 基礎設施已經建好，團隊只需要把應用程式的新版本自動佈署到既有的 EC2 執行個體。哪一個服務最合適？

- (A) AWS CloudFormation
- (B) AWS Elastic Beanstalk
- (C) AWS Lambda
- (D) AWS CodeDeploy

**30.** 下列哪兩項敘述正確？（選兩項）

- (A) KMS 用來建立與管理加密金鑰
- (B) Secrets Manager 可以自動輪替資料庫憑證
- (C) Artifact 蒐集客戶自己使用 AWS 的稽核證據
- (D) GuardDuty 掃描 EC2 的軟體漏洞
- (E) 使用 Lambda 時，客戶需要自行管理作業系統的修補
