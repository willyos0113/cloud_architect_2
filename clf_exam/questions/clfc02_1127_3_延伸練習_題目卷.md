## 一、雲端概念（8 題）

**1.** 公司要把機房裡的應用程式伺服器盡快搬到 AWS，不更動應用程式的程式碼與架構，原樣遷移。這屬於哪一種 6R 遷移策略？

- (A) Rehost
- (B) Replatform
- (C) Refactor
- (D) Repurchase

**2.** 公司決定停止維護自己架設的客戶關係管理（CRM）系統，改用 SaaS 型的 CRM 產品。這屬於哪一種 6R 遷移策略？

- (A) Rehost
- (B) Retire
- (C) Repurchase
- (D) Retain

**3.** 公司把應用程式搬到 AWS 時，核心架構維持不變，只是把自己架設與維護的資料庫改成由 Amazon RDS 代管。這屬於哪一種 6R 遷移策略？

- (A) Rehost
- (B) Replatform
- (C) Refactor
- (D) Retain

**4.** 盤點既有系統時發現某個舊報表系統已經沒有人使用，團隊決定不遷移，直接關閉。這屬於哪一種 6R 遷移策略？

- (A) Retain
- (B) Rehost
- (C) Replatform
- (D) Retire

**5.** 新專案的開發環境過去需要數週才能採購並架設完成，現在只要數分鐘就能建立，團隊因此能更快嘗試新想法。這是雲端運算的哪一項優點？

- (A) 彈性
- (B) 高可用性
- (C) 敏捷性
- (D) 全球觸及

**6.** 電商在促銷期間，系統自動增加容量來應付尖峰流量，活動結束後自動縮減，只為實際使用的資源付費。這是雲端運算的哪一項優點？

- (A) 彈性
- (B) 敏捷性
- (C) 經濟規模
- (D) 全球觸及

**7.** 財務長希望建立雲端成本的可視性與管控機制，並管理雲端相關的風險。這屬於 Cloud Adoption Framework（CAF）的哪一個視角？

- (A) People
- (B) Business
- (C) Governance
- (D) Platform

**8.** 公司要提升員工的雲端技能、調整組織文化並規劃訓練。這屬於 Cloud Adoption Framework（CAF）的哪一個視角？

- (A) Security
- (B) Operations
- (C) Platform
- (D) People

## 二、安全與合規（6 題）

**9.** 公司使用 AWS Organizations 管理多個帳戶，希望在組織層級限制成員帳戶能使用的服務，即使成員帳戶的管理員也無法超越。哪一個功能最合適？

- (A) IAM Policy
- (B) Service Control Policies（SCP）
- (C) Network ACL
- (D) Security Group

**10.** 下列哪兩項關於 Service Control Policies（SCP）的敘述正確？（選兩項）

- (A) SCP 可以設定成員帳戶的權限上限
- (B) 只要附加 SCP，就會直接授予使用者權限
- (C) 即使是帳戶管理員，也無法超越 SCP 允許的範圍
- (D) SCP 只對 Organizations 的管理帳戶有效
- (E) SCP 可以取代所有 IAM 政策

**11.** 網路工程師需要在子網路層級套用規則，規則是無狀態的，並且需要能夠明確地拒絕特定的 IP 位址。哪一個功能最合適？

- (A) Security Group
- (B) IAM Role
- (C) AWS WAF
- (D) Network ACL

**12.** 公司的員工需要使用同一組登入，單一登入（SSO）存取多個 AWS 帳戶與商業應用程式。哪一個服務最合適？

- (A) Amazon Cognito
- (B) IAM User
- (C) AWS IAM Identity Center
- (D) AWS KMS

**13.** 公司開發的行動應用程式，需要讓一般消費者自行註冊、登入，並可使用社群帳號登入。哪一個服務最合適？

- (A) Amazon Cognito
- (B) AWS IAM Identity Center
- (C) IAM Role
- (D) AWS Directory Service

**14.** 公司要自動找出 S3 儲存貯體中的個人識別資訊（PII）等敏感資料。哪一個服務最合適？

- (A) Amazon Inspector
- (B) Amazon Macie
- (C) Amazon GuardDuty
- (D) AWS Config

## 三、雲端技術與服務（10 題）

**15.** 下列哪兩項是 EC2 Instance store 的特性？（選兩項）

- (A) 屬於連接到主機的實體儲存，延遲低、IOPS 高

- (C) 可以建立快照並備份到 S3
- (D) 獨立於執行個體的生命週期，資料永久保存
- (E) 可以同時掛載到不同可用區域的多台執行個體

**16.** 單一 EC2 執行個體需要一個可持久保存的區塊儲存，用作資料庫磁碟，並且希望能定期建立快照。哪一個選項最合適？

- (A) Instance store
- (B) Amazon S3
- (C) Amazon EFS
- (D) Amazon EBS

**17.** 多台 Linux 的 EC2 執行個體需要同時掛載同一個共用的檔案系統，容量會自動伸縮。哪一個服務最合適？

- (A) Amazon EBS
- (B) Amazon EFS
- (C) Amazon S3 Glacier
- (D) Instance store

**18.** 公司要在地端機房與 AWS 之間建立專用的私有連線，連線不經過公共網際網路，要求頻寬與延遲穩定。哪一個服務最合適？

- (A) AWS Site-to-Site VPN
- (B) AWS Transit Gateway
- (C) AWS Direct Connect
- (D) Amazon CloudFront

**19.** 公司要在幾小時內快速建立地端與 AWS 之間的加密連線，可以接受連線經過公共網際網路，也不想等待專線佈建。哪一個服務最合適？

- (A) AWS Site-to-Site VPN
- (B) AWS Direct Connect
- (C) AWS Global Accelerator
- (D) AWS PrivateLink

**20.** 位於私有子網路的 EC2 執行個體需要連到網際網路下載更新，但不能被網際網路上的主機主動連入。哪一個選項最合適？

- (A) Internet Gateway
- (B) VPC Peering
- (C) Security Group
- (D) NAT Gateway

**21.** 資料的存取模式不固定且難以預測，公司希望 AWS 依存取頻率自動在不同儲存層之間移動，不想自己設定生命週期規則。哪一個 S3 儲存類別最合適？

- (A) S3 Standard
- (B) S3 Glacier Deep Archive
- (C) S3 Intelligent-Tiering
- (D) S3 One Zone-IA

**22.** RDS 資料庫的讀取查詢量大增，造成主資料庫負載過高，公司希望把讀取流量分攤到其他執行個體。哪一個功能最合適？

- (A) Multi-AZ 部署
- (B) Read Replica
- (C) RDS 快照
- (D) Auto Scaling

**23.** 公司希望 RDS 主資料庫發生故障時，能自動切換到另一個可用區域的備用資料庫，資料同步複寫。哪一個功能最合適？

- (A) Read Replica

- (C) Multi-AZ 部署
- (D) Elastic IP

**24.** 團隊要執行容器化的應用程式，但不想自己佈建與管理 EC2 執行個體。哪一個選項最合適？
