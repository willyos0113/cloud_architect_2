## 一、Artifact 與 Audit Manager（6 題）

**1.** 客戶在審查供應商時，要求公司提供 AWS 資料中心的 ISO 27001 認證報告。公司應該使用哪一個服務取得？

- (A) AWS Audit Manager
- (B) AWS Artifact
- (C) AWS Config
- (D) Amazon Inspector

**2.** 內部稽核每季都要整理公司帳戶中的 IAM 與 CloudTrail 設定等證據，並對照 PCI DSS 的控制項產生稽核報告，希望能自動化。哪一個服務最合適？

- (A) AWS Artifact
- (B) AWS Trusted Advisor
- (C) AWS Audit Manager
- (D) AWS CloudTrail

**3.** 公司在處理醫療資料前，需要先在 AWS 上簽署 Business Associate Addendum（BAA）這類協議。哪一個服務可以管理這些協議？

- (A) AWS Audit Manager
- (B) AWS Config
- (C) AWS Trusted Advisor
- (D) AWS Artifact

**4.** 下列哪兩項是 AWS Audit Manager 的特性？（選兩項）

- (A) 提供預先建置的合規框架，如 PCI DSS 與 HIPAA，並對應到控制項
- (B) 下載 AWS 本身的 SOC 報告
- (C) 持續自動蒐集客戶自己環境中的稽核證據
- (D) 偵測與已知惡意 IP 的通訊
- (E) 簽署 AWS 的合規協議

**5.** 下列哪一項敘述正確區分了 Artifact 與 Audit Manager？

- (A) Artifact 蒐集客戶自己的稽核證據；Audit Manager 下載 AWS 的合規報告
- (B) 兩者都只能下載 AWS 的合規報告
- (C) Artifact 提供 AWS 的合規報告與協議；Audit Manager 蒐集客戶自己環境的稽核證據
- (D) 兩者都是自動蒐集客戶環境證據的服務

**6.** 公司要通過 SOC 2 稽核，稽核員提出兩項需求：（一）取得 AWS 資料中心的控制報告；（二）取得公司自己帳戶中的存取控制證據。哪兩個服務分別滿足這兩項需求？（選兩項）

- (A) AWS Artifact
- (B) AWS Audit Manager
- (C) Amazon GuardDuty
- (D) Amazon Inspector
- (E) Amazon Macie

## 二、計價方案（5 題）

**7.** 團隊要進行為期三天的壓力測試，伺服器若被中斷，整個測試就要重來，結束後立即關閉，也不想簽任何承諾。哪一個方案最合適？

- (A) Compute Savings Plans
- (B) Standard Reserved Instances
- (C) Spot Instances
- (D) On-Demand Instances

**8.** 公司已購買一年期的 Compute Savings Plans，之後新增了 Lambda 工作負載。關於這個新增的工作負載，哪一項敘述正確？

- (A) 不會享有折扣，Savings Plans 只適用 EC2
- (B) 會享有折扣，Compute Savings Plans 涵蓋 EC2、Fargate 與 Lambda
- (C) 不會享有折扣，需要另外購買 Lambda 專用的 Reserved Instances
- (D) 會享有折扣，但必須先轉換為 Convertible Reserved Instances

**9.** 夜間的影片轉檔任務若被中斷，可以自動重新排入佇列再執行，公司希望成本最低。哪一個方案最合適？

- (A) Standard Reserved Instances
- (B) Compute Savings Plans
- (C) Spot Instances
- (D) Dedicated Hosts

**10.** 下列哪一項是 Reserved Instances 與 Savings Plans 的共同點？

- (A) 都以一年或三年的使用承諾換取折扣
- (B) 都保證容量不會被 AWS 回收
- (C) 都可以隨時取消並全額退費
- (D) 都只適用於 EC2

**11.** 關於 Compute Savings Plans 與 EC2 Instance Savings Plans，下列哪一項敘述正確？

- (A) EC2 Instance Savings Plans 的彈性高於 Compute Savings Plans
- (B) Compute Savings Plans 可以更換家族與 Region，並涵蓋 Fargate 與 Lambda
- (C) Compute Savings Plans 綁定特定的執行個體家族
- (D) Compute Savings Plans 只適用於 EC2

## 三、Lambda／Beanstalk／Lightsail 與 Secrets Manager／KMS／ACM（4 題）

**12.** 公司的網站需要 HTTPS 的 SSL/TLS 憑證，並希望 AWS 自動處理憑證續期。哪一個服務最合適？

- (A) AWS Secrets Manager
- (B) AWS Key Management Service（KMS）
- (C) AWS Certificate Manager（ACM）
- (D) AWS IAM

**13.** 個人部落格需要一個簡單的方案：包含虛擬伺服器、儲存、網路與靜態 IP，以固定月費計價，並且不想研究 VPC 設定。哪一個服務最合適？

- (A) AWS Lambda
- (B) Amazon Lightsail
- (C) AWS Elastic Beanstalk
- (D) Amazon EC2

**14.** 公司有一個長時間執行的 Python Web 應用程式，想快速上雲，不想自己設定 EC2 與負載平衡，也不想把應用程式重寫成函式。哪一個服務最合適？

- (A) AWS Lambda
- (B) AWS CodeDeploy
- (C) AWS CloudFormation
- (D) AWS Elastic Beanstalk

**15.** 開發者不想把 API 金鑰寫死在程式碼裡，希望程式執行時安全地取得，並且定期自動輪替。哪一個服務最合適？

- (A) AWS Secrets Manager
- (B) AWS Key Management Service（KMS）
- (C) AWS Certificate Manager（ACM）
- (D) AWS Artifact
